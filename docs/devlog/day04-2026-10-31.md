## 완료와 구분해 남긴 항목

- 구조 통과는 의미 정확도 100%나 반복 안정성 보증이 아니다. P01 배송 옵션 설명 생략·R01 의사 확인 문구, 조사 민감도와 범위 밖 자유 문장 검증 한계를 남긴다.
- 5일차의 재검색·상한·실패 종료·실행 내역·화면/응답 타입 연결은 이미 선행 구현·검증했고 main에 반영했다. 통신 단절/서버 오류의 브라우저 동작·중복 요청 계측 등 남은 화면 검증을 구분하므로 5일차 전체 완료로 표시하지 않는다.
- 6일차의 Docker 단일 서비스·고정 SQLite/벡터 복원·로컬 재시작 검증도 main에 반영했다. 실제 Linux Docker 검증은 당시 v6 이미지 기준이며 최신 이미지/원격 배포는 미실행이므로 6일차 전체 완료가 아니다.
- 7일차에 쓸 평가/문제 해결 자료는 누적했지만 최종 포트폴리오 설명·시연은 아직 마감하지 않았다.

다음은 [단계별 현황](../initial-design.md#milestone-status)의 미완료 범위부터 진행한다. 이번 요청은 일차/날짜/진행 상태 정리이며 새 기능이나 새 학습 과제는 만들지 않는다. 기존 로컬 Python 학습과 미풀이 과제는 그대로 유지한다.
