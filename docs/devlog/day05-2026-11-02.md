## 발견한 문제와 변경

인용 링크는 접힌 출처의 위치로만 이동해 본문을 바로 읽을 수 없었다. 출처 DOM을 ID별 ref로 보관하고 인용을 누르면 펼침/초점을 함께 처리했다. 상세 원인·대안·검증 전후는 [D20](../decisions.md#d20)에 기록한다. 상담 API 계약·Python·주문/정책/평가 정답·프롬프트는 변경하지 않았다.

기존 GitHub 검사 작업에 Chromium 설치와 같은 UI 검사 명령을 추가했다. **이번 원격 CI는 진행 중**이며 완료 결과는 마감 기록에 덧붙인다. 과거 CI 성공과 혼동하지 않는다.
