## 완료한 작업

- 상태·판단·조회·검색·종료 노드와 조건 edge를 직접 정의했다. LLM이 NextAction으로 행동/검색어/답변을 제안하고 서버가 LangChain 도구를 실행한다. 그래프 안에 다른 에이전트 실행기는 두지 않았다.
- 실제 조회 결과와 검색 출처를 응답에 사용한다. 주문번호는 요청에서만 가져오며 모델은 주문 객체나 URL·수집일을 생성하지 않는다. 없는 주문·모호한 품목·unknown 상태·반품 수령일 누락, 모델·도구·인용 오류를 분기한다.
- 실행 전 전체 도구 3회·조회 1회·검색 2회와 모델 판단 4회 제한을 적용했다. 한 번 충분하면 끝내고 부족할 때만 재검색한다.
- POST /api/consultations의 501을 실제 그래프 실행으로 교체했다. 기본 API 비활성은 200/system_error로 안전하게 종료한다. OpenAPI 스냅샷과 health boolean 타입을 함께 갱신했다.
- React 상담 화면 하나에서 문의·선택 주문/품목을 보내고 주문·정책/출처 링크·추천·초안·추가 확인·도구 내역을 표시한다. 실제 JSON은 Zod 검증 후 타입이 있는 props·화면 상태로 전달한다.
- [설계와 역할](../agent-flow.md), [API 계약](../api-contract.md), [판단 기록](../decisions.md#d07)을 갱신했다. 의존성은 설치된 잠금 버전을 유지했다.
