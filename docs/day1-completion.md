**1일차 범위는 완료했다.** 평가 정의 검증은 실제 검색 정확도·AI 상담 품질 평가와 다르다. 상담 API의 501은 의도된 미구현 표시이며 완성된 상담 서비스가 아니다.

이번 추가 작업에서도 유료 OpenAI 호출·임베딩·외부 배포·Git push는 하지 않았다. 원문을 다시 수집한 요청만 네트워크를 사용했다.

검증 결과: 백엔드 pytest 21개 통과, ruff 검사 통과, React TypeScript 검사·계약 검사·Vite 빌드 통과. 정책 3문서·11규칙 묶음의 출처·해시·정리 결과와 평가 24사례의 주문/품목·날짜·예상 도구 상한이 일치했다. 기존 주문 DB는 변경하지 않았다.

다음 2일차 작업:

1. 검수된 rule_groups.json의 공식 본문과 제목을 청킹한다. 조건/예외·관련 묶음을 보존한다.
2. 고정 임베딩 모델·차원으로 적재하고 본문 해시에 따른 재사용을 구현한다.
3. Chroma 검색과 출처 반환을 구성한다.
4. 24사례 중 검색 대상 질문으로 Recall@4와 근거 부족 사례를 평가한다.
