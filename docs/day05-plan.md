## 작업 범위

- 남은 UI/오류 검증은 **모의 응답·계약 예시 등 비용 없는 로컬 방식부터** 수행한다. 검증용 응답을 실제 AI 성공으로 표시하지 않고 운영 화면에 가짜 성공 경로나 공개 디버그 API를 추가하지 않는다.
- 이미 검증한 그래프를 다시 만들거나 모든 유료 평가를 습관적으로 반복하지 않는다. 동작을 수정했다면 영향받는 회귀부터 확인하고, 전체/실제 API 재평가는 변경 영향과 남은 우려에 따라 결정한다.
- 한 화면 MVP를 유지한다. 모바일/장식 개선은 여유가 있을 때 별도 판단하고 필수 범위를 늘리지 않는다.
- P01/R01 문구 개선과 조사 민감도·프롬프트 전체 정리는 기존 후속 항목으로 유지한다. 이 계획만으로 자동 착수하지 않는다.
- 최신 Docker 이미지·원격 배포·배포 환경 AI/재시작 검증은 **6일차 범위**다. 최종 포트폴리오·시연은 7일차로 구분한다.
